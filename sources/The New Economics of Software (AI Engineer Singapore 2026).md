# The New Economics of Software (AI Engineer Singapore 2026)

**Source**: AI Engineer Singapore, 16 May 2026 — Max Buckley, Head of Knowledge Research, Exa AI
**Created**: 2026-05-17

## Summary

Max Buckley frames the shift from software scarcity to abundance as an economic transformation. The collapse of development costs moves bottlenecks from implementation to attention, governance, and judgment. Deep technical knowledge remains essential — not for writing code, but for directing agents with precision ("jagged intelligence").

## Key Points

- **Scarcity collapse**: The old rule of "whittle 30 ideas down to 3" no longer applies. Low-cost experimentation allows the long tail of ideas to be evaluated and discarded efficiently.
- **SaaS moats erode**: If a CRUD app can be replicated in a weekend, code is no longer the main competitive advantage. Moats shift to brand, data, ML models, and integration.
- **Bottlenecks shift to attention and governance**: Prototyping is no longer a constraint. The scarce resource is attention, not implementation. Code review becomes insufficient when agents produce code faster than humans can evaluate it.
- **New meta: measurement, ideation, iteration**: Rapid building makes measurement the true bottleneck — profiling, benchmarks, A/B testing, and user behavior metrics. Discernment (identifying which ideas are worth pursuing) becomes the limiting factor.
- **Jagged intelligence**: AI agents may know the answer but will not surface it unless prompted correctly. Deep technical knowledge remains essential — not to code faster, but to ask, evaluate, and direct effectively. The agent executes; humans provide judgment.
