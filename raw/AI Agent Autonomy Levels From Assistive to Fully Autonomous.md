## Five Levels of AI Agent Autonomy

### Level 1: Assistive (Autocomplete)
The agent offers suggestions requiring explicit human acceptance before acting. Zero autonomous actions. Humans review every output. Lowest risk, lowest leverage.
- **Example:** GitHub Copilot predicting code, developer presses Tab to accept.

### Level 2: Advisory (Copilot)
The agent evaluates context and recommends multi-step actions, but humans approve each one. Drafts responses or proposes plans, requires approval before execution.
- **Example:** A support assistant that drafts email responses for review, or a coding tool proposing refactoring.

### Level 3: Supervised Autonomous
The agent acts independently within set boundaries, escalating uncertain or high-stakes decisions. Uses confidence thresholds that trigger human review, action allowlists, budget or impact limits.
- **Example:** Most production AI agents in 2026 operate at this level.

### Level 4: Monitored Autonomous
The agent works independently across a wide action space while humans track aggregate results. Oversight shifts from per-action approval to outcome-based oversight, intervening only when metrics drift.

### Level 5: Fully Autonomous
The agent defines its own goals, gathers resources, and operates without human oversight. No production system genuinely operates at this level today.

## The Practical Boundary

The gap between Level 3 and Level 5 is where the agency debate lives. Level 3 keeps humans in the loop on hard decisions. Level 4 moves humans to monitoring posture. Level 5 removes them entirely.

Most systems that claim "autonomous" today are Level 3 with good marketing.
