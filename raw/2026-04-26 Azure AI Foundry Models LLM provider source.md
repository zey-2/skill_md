Captured: 2026-04-26

Primary source:

## Source Summary

Azure Foundry Models is Microsoft's model hub for discovering and deploying foundation models. Microsoft describes the catalog as including popular large language and vision foundation models curated by Microsoft, OpenAI, Anthropic Claude, DeepSeek, xAI, Hugging Face, Meta, Mistral AI, Cohere, Deci, Stability AI, Nixtla, and NVIDIA.

For powering AI tools, Azure is most relevant when the tool needs enterprise governance, Microsoft ecosystem integration, Azure OpenAI access, and a broad model catalog under Azure procurement and security controls.

## Provider Notes

- Azure Foundry Models advertises more than 11,000 models packed for out-of-the-box use and shared compute resources.
- Foundry Models includes Microsoft, OpenAI, Anthropic, Cohere, DeepSeek, Mistral AI, Meta, xAI, Hugging Face, and other model sources.
- Microsoft describes Serverless API / Models as a Service as a deployment type for hosted inference and fine-tuning without provisioning GPUs.
- Serverless API availability includes Anthropic Claude, Meta Llama, Mistral AI, Cohere, Core42 JAIS, Nixtla, Stability, DeepSeek, BFL, Bria AI, and xAI Grok models.

## AI Tool Fit

- Strong candidate for organizations already using Azure, Microsoft 365, GitHub, Entra ID, or Azure OpenAI.
- Useful when a tool needs model choice without leaving the Azure security and billing perimeter.
- Especially relevant for enterprise apps that must satisfy procurement, compliance, and identity requirements.
