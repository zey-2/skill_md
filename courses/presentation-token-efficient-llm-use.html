Effort Tuning

The effort parameter controls how many tokens the model spends reasoning. Most tasks don't need maximum depth. Start at medium — the Pareto-optimal default.

low ~1/5 tokens — subagents, bulk work
medium ~1/3 tokens — most tasks, default

Prompt Caching

Store KV representations of processed prefixes. Subsequent requests with identical beginnings skip recomputation. The catch: exact prefix matching — any change invalidates everything downstream.

For high hit rates

1 Static content first, dynamic last
2 Identical prefixes across requests
3 Pre-warm caches at startup
4 Use 1-hour TTL for agent sessions

Context Compression

Strip noise before tokens reach the model. LLMLingua-2 achieves 2–5x compression while preserving 89% accuracy. On code, compression can actually improve output — removing noise that confused the model.

✗ Multi-hop reasoning chains
✗ Exact numbers, names, dates

Context Rot

More context isn't always better. Quality degrades well before the window fills. The effective context for most models is 25–50% of the claimed limit.

Safe zone 60% — quality cliff Compaction
Kilo Code engineersDegrades at 60% fill

RULE OF THUMB: Size tasks so agents finish before 60% context fill.

Code Over Inference

The most efficient token is the one never sent. Prefer deterministic code over AI inference for routine work. Cheaper, faster, repeatable.

CLAUDE CODE ITSELF

98.4% deterministic infrastructure
1.6% actual AI inference

VILA-Lab analysis of ~512K lines of source code

// Save scripts inside skills // Trade AI tokens for code compute function formatOutput(data) { // Deterministic — zero tokens return data .filter(d => d.score > 0.5) .map(d => `${d.name}: ${d.value}`) .join('\n'); } // vs. asking the LLM to format // = wasted tokens every call

Tokenmaxxing

The meta-strategy: spend tokens deliberately when they buy real output. The goal isn't fewer tokens — it's better outputs per token. More calls, more context, more verification — when each token earns its keep.

"The useful ratio is outputs over tokens. When token volume becomes a target, people game the metric."
