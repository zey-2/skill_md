SKILL.md Deep Dive

03 — PACKAGE ANATOMY

The Skill Package

A skill is a portable unit of agent knowledge. The file structure is intentional.

SKILL.md
references/
scripts/
assets/
  • SKILL.md — Main instruction file. The agent reads this when the skill triggers.
  • references/ — Background docs, API schemas. Loaded on demand.
  • scripts/ — Deterministic helpers. Run when the workflow needs them.
  • assets/ — Templates, images, static files.

03 — FRONTMATTER

Frontmatter is Everything

name + description = the routing mechanism

The agent sees ONLY these fields to decide if the skill applies.

Description = triggering conditions ONLY

Not what the skill does. Not the workflow. Just WHEN to use it.

Start with "Use when..."

Third person. Under 500 characters.

Example: bad vs good description

Bad: "Do a code review" — Claude does ONE pass and stops. The multi-stage review in the skill body is never triggered.

Good: "Run a two-stage code review after each task" — Agent knows to expect two passes before moving on.

03 — PROGRESSIVE DISCLOSURE

Progressive Disclosure

Layer 1
Metadata
Layer 2
SKILL.md Body
Layer 3
References
↓
↓
  • Layer 1: Metadata (~100 tokens) — name + description
  • Layer 2: SKILL.md Body (~500 lines) — instructions, steps, constraints
  • Layer 3: References (on-demand) — API docs, schemas, scripts

If it's too long for the main file, put it in references/ and link to it.

How Skills Are Built

04 — CREATION APPROACHES

3 Approaches to Creating Skills

1

matt pocock

grill → draft → iterate

  • Grill the human before building
  • Draft the SKILL.md together
  • Iterate from real usage

Best for: personal skills, quick team conventions

2

superpowers

RED → GREEN → REFACTOR

  • Run WITHOUT skill first — watch it fail
  • Write skill to fix those failures
  • Re-test under pressure — close loopholes

Best for: discipline-enforcing, quality-critical

3

anthropic skill-creator

eval viewer + benchmarking

  • Write 3-5 test prompts for real tasks
  • Run with-skill and baseline comparisons
  • Grade quantitatively with eval viewer

Best for: objectively verifiable outputs

AI Risks

05 — RISKS

Skills Are Powerful. They Run on Your Machine.

Risks

Prompt Injection

most common

Hidden instructions that override agent behavior

Supply Chain Risk

most likely

Installing skills from unverified authors

Data Exfiltration

most dangerous

Scripts that read and transmit sensitive files

Defenses

Read Before Installing

Review SKILL.md and scripts before adding

Trust Verified Sources

Known authors, official registries, peer-reviewed repos

Principle of Least Surprise

A skill's contents should not surprise you in their intent

Skills are code. Treat them like code.
